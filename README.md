HR Analytics & Employee Insights Using MySQL

📌 Project Overview

This project focuses on analysing HR employee data using MySQL to generate meaningful business insights and support data-driven HR decision-making.

The project explores employee distribution, salary trends, departmental performance, employee experience, attendance and performance analysis using SQL.

🎯 Project Objectives

- Analyse overall employee distribution.
- Identify department-wise employee strength.
- Analyse salary trends across departments.
- Identify highest and lowest-paid employees.
- Evaluate employee performance.
- Analyse attendance patterns.
- Explore employee experience and workforce trends.
- Generate meaningful business insights for HR decision-making.

🛠️ Tools & Technologies

- MySQL 8.0+
- MySQL Workbench
- SQL

📂 Database Structure

The project uses the following five tables:

1. Employees
2. Departments
3. Salary_History
4. Attendance
5. Performance_Reviews
